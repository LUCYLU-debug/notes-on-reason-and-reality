# Paradoxes & Incompleteness

<div class="chapter-lede">A sentence points back to itself. A set is defined by whether it contains itself. Suddenly an apparently harmless rule becomes a problem.</div>
<div class="chapter-info"><span>2 hours</span><span>Reading + one formal argument</span><span>No full theorem proof required</span></div>

## What to learn

- Explain the role of **self-reference** in the liar paradox, without assuming every self-referential statement is paradoxical.
- Derive Russell's contradiction from the unrestricted comprehension principle in naïve set theory.
- State the first incompleteness theorem with its important qualifications: the system must be sufficiently expressive, consistent, and effectively axiomatised (in a standard formulation).
- Separate **semantic truth** from **formal provability**; do not turn Gödel's theorem into an unrestricted claim about the limits of minds or machines.

## Questions to carry

1. What exactly makes the liar sentence troublesome?
2. Why was Russell's paradox a challenge to naïve set theory?
3. What can an incomplete formal system still establish?
4. Can a theorem about proof systems settle broader philosophical questions by itself?
